# 🤖 Solana AI Copilot (Powered by Gemini 3.8 Flash)

An intelligent on-chain Web3 AI assistant built on Solana Devnet. Seamlessly combines natural language agentic interactions with Solana blockchain infrastructure.

🔗 **Live Demo:** [https://solana-ai-copilot-66ks.vercel.app/](https://solana-ai-copilot-66ks.vercel.app/)

---

## ⚡ Features
- 🚀 **High-Speed AI Engine:** Powered by Google's `Gemini 3.8 Flash` via streaming AI SDK.
- 👛 **Solana Wallet Integration:** Full support for Phantom & Solflare with instant cluster detection.
- ⛓️ **On-Chain Awareness:** Context-aware prompts capable of reading user wallet states, network metadata, and devnet parameters.
- 🎨 **Modern Cyberpunk UI:** Built with Tailwind CSS, responsive dark mode, and sleek glassmorphism.

---

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Blockchain:** Solana Web3.js v3, `@solana/wallet-adapter`
- **AI Engine:** Google Gemini 3.8 Flash (`@ai-sdk/google`, Vercel AI SDK)
- **Deployment:** Vercel CI/CD
